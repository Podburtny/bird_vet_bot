# Bird Vet Bot

Telegram-бот для консультаций по домашней птице (куры и перепела).

## Стек

- Python 3.11+
- aiogram 3
- Supabase Postgres
- Supabase Storage
- OpenRouter
- APScheduler
- Sentry

## Локальный запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Podburtny/bird_vet_bot.git
cd bird_vet_bot
